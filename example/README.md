# The example site

A portfolio of Ivy Lambda, a developer who doesn't exist, built with gensane. It uses every kind of content and every Markdown feature,
so it shows what a site can look like, and the test suite builds it on every change with no warnings, and checks that every page is
valid and accessible.

To see it while you change it, from the repository's folder:

```sh
pnpm example
```

This builds gensane and serves the site at `http://localhost:4000/`. It is published at <https://gensane.dev/example/>.
